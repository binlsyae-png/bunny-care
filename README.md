# 🐰 버니 케어 (Bunny Care) - 토끼 육성 시뮬레이션 게임 (와이드 에디션)

파스텔 핑크와 부드러운 크림색을 바탕으로 디자인된 아기자기하고 사랑스러운 웹 기반 토끼 육성 시뮬레이션 게임입니다.

---

## 🌐 온라인 바로 플레이하기 (Vercel 배포)
- **온라인 배포 주소**: **[https://bunny-care-ashy.vercel.app](https://bunny-care-ashy.vercel.app)**
- **깃허브 저장소**: **[https://github.com/binlsyae-png/bunny-care](https://github.com/binlsyae-png/bunny-care)**

## 🎮 게임 실행 방법

### 방법 1. 온라인 웹 링크 접속 (추천)
- [https://bunny-care-ashy.vercel.app](https://bunny-care-ashy.vercel.app) 에서 PC/모바일 언제든 바로 플레이 가능합니다.

### 방법 2. 브라우저에서 바로 열기
- `index.html` 파일을 더블 클릭하여 웹 브라우저에서 바로 실행합니다.

### 방법 3. 로컬 웹 서버로 열기
- 로컬 포트 3000에 경량 서버 구동:
  ```bash
  node local-server.js
  ```
- 브라우저 주소창에 `http://localhost:3000` 접속

## ✨ 4대 핵심 개선 사항

### 1. 🐰 토끼의 행동과 소리 다양화
- **풍부한 자율 행동**: 8~16초마다 귀 쫑긋거리기(`ear_wiggle`), 코 씰룩거리며 냄새 맡기(`sniffing`), 앞발로 세수하기/그루밍(`grooming`), 기지개 켜기(`stretching`), 몸 털기(`shaking`), 깡충 점프(`jumping`)를 무작위로 보여줍니다.
- **연속 쓰다듬기 분기 반응**: 쓰다듬을 때마다 눈을 지그시 감기, 귀를 뒤로 눕히기, 몸을 납작하게 낮추기, 고개를 갸웃거리기 등 4가지 서로 다른 반응과 대사가 출력됩니다.
- **상황별 자연스러운 사운드**:
  - 코 킁킁 소리 (`sniff`)
  - 발 구르기 쿵 소리 (`thump`)
  - 당근 아삭 씹는 소리 (`crunch`)
  - 건초/딸기 오물오물 소리 (`nibble`)
  - 기지개/털 털기 부스럭 소리 (`rustle`)
  - 행복할 때 이를 부딪히는 치아 골골 소리 (`toothPurr`)
  - 상단 우측 `🔊` 버튼으로 언제든지 소리를 켜고 끌 수 있습니다.

### 2. 🥕 먹이를 실제로 보이게 만들기 (실시간 인터랙션)
- 당근(🥕), 건초(🌾), 딸기(🍓), 클로버(🍀) 등 선택한 먹이가 선명하고 정교한 일러스트 그래픽으로 화면에 나타납니다.
- 손이 먹이를 들고 토끼 입 앞으로 슥 다가가는 자연스러운 애니메이션이 재생됩니다.
- 토끼가 고개를 숙이고 오물거리며 먹이를 먹는 동안, 먹이의 크기가 **100% → 75% → 50% → 25% → 0%**로 조금씩 베어물리며 줄어들고 부스러기 파티클이 흩날립니다.
- 다 먹으면 손이 자연스럽게 들어가고 토끼가 입맛을 다시며 만족한 표정과 대사를 보여줍니다.

### 3. 💖 친밀도 제한 없는 데이트와 짝짓기
- **친밀도 수치 및 게이지 완전 삭제**: 복잡하거나 불필요한 친밀도 제약이 없습니다.
- **언제든 자유로운 데이트**: 성체 토끼라면 원할 때 언제든지 데이트 버튼을 눌러 가족 토끼나 마을의 멋진 토끼들과 데이트를 즐길 수 있습니다.
- **꽃밭 데이트 연출**: 꽃잎이 흩날리는 낭만적인 정원에서 두 토끼가 서로를 향해 깡총깡총 다가가 코를 맞대며 뽀뽀하는 애니메이션이 펼쳐집니다.
- **즉시 짝짓기(번식)**: 데이트 후 화면에 나타나는 `[💖 지금 바로 짝짓기 시작하기 (아기 만들기) 🍼]` 버튼을 누르면 즉시 임신 카운트다운(60초)이 시작됩니다.
- **임신 & 출산**: 출산 타이머를 실시간으로 확인할 수 있으며, 필요 시 `[즉시 출산]` 버튼으로 바로 1~4마리의 아기 토끼를 탄생시키고 이름을 지어줄 수 있습니다 (부모 털색과 무늬 유전 상속).

### 4. 🖥️ 가로 와이드 16:9 레이아웃
- PC 화면의 가로 폭을 최대로 살리는 16:9 와이드 비율(너비 약 1240px)로 시원하게 개편되었습니다.
- **좌측 패널**: 토끼 프로필, 4대 건강 스탯(배부름, 기분, 건강, 기운), 성장 게이지, 먹이 보관함 실시간 수량
- **중앙 무대**: 실제 반려토끼 룸 사진 배경의 넓은 생활 공간(원목 케이지, 건초 바구니, 물그릇, 장난감 공)과 큼직하고 돋보이는 실제 토끼 캐릭터
- **우측 패널**: 밥 주기, 쓰다듬기, 놀아주기, 낮잠자기 액션 버튼, 데이트 & 짝짓기 바로가기, 하단 산책/가족/도감/상점 내비게이션
- 모바일 접속 시 세로 스택형으로 자동 재배치되어 모든 디바이스에서 최적의 플레이 환경을 제공합니다.
